Vamos iniciar a Fase 3 do arqdor.ai.

IMPORTANTE

Não quero apenas evoluir o frontend.

Quero mudar a arquitetura do módulo.

O arqdor.ai deixa de ser um Prompt Builder.

Ele passa a ser um Sistema de Modelagem Arquitetônica para Inteligência Artificial.

O Prompt passa a ser apenas uma saída do sistema.

O ativo principal será o Projeto Arquitetônico Estruturado.

IMPORTANTE

Nesta etapa NÃO conectar IA.

NÃO alterar backend.

NÃO remover nada.

Apenas reorganizar a arquitetura do frontend para suportar essa estrutura.

Criar todos os modelos TypeScript.

Criar árvore de objetos.

Criar Inspector.

Criar biblioteca.

Criar ProjectDNA.

Criar Versionamento.

Criar estrutura preparada para integração futura.

O objetivo desta etapa é transformar o arqdor.ai em uma plataforma de modelagem arquitetônica para IA, onde o Prompt é apenas uma consequência da estrutura do projeto.
