🔴 TAREFA 1 (Hoje) — Rate Limiting + Helmet (Segurança)
Instale os pacotes:
npm install express-rate-limit helmet

No arquivo principal do servidor (ex: index.ts ou server.ts), LOCALIZE a seção onde o Express é configurado (app.use). Adicione ESTE BLOCO:

import rateLimit from 'express-rate-limit';
import helmet from 'helmet';

// 1. Helmet para headers de segurança
app.use(helmet());

// 2. Limitador para rotas de autenticação
const authLimiter = rateLimit({
  windowMs: 1 * 60 * 1000, // 1 minuto
  max: 5, // 5 tentativas
  skipSuccessfulRequests: true, // não bloqueia quem acertou a senha
  handler: (req, res) => res.status(429).json({ error: 'Muitas tentativas. Aguarde 1 minuto.' })
});

// Aplicar SOMENTE nas rotas críticas
app.use('/api/auth/login', authLimiter);
app.use('/api/auth/forgot-password', authLimiter);

Após aplicar, reinicie o servidor e teste: faça 6 requisições erradas para /login em 1 minuto. A sexta deve retornar HTTP 429.

🟢 TAREFA 3 (Próximos 15 dias) — RBAC (Permissões por Papel)
Crie um middleware em src/middleware/authorize.ts:

import { Request, Response, NextFunction } from 'express';

export const authorize = (...allowedRoles: string[]) => {
  return (req: Request, res: Response, next: NextFunction) => {
    const user = (req as any).user; // vem do authenticate
    if (!user) return res.status(401).json({ error: 'Não autenticado' });
    
    const { platformRole } = user;
    if (!allowedRoles.includes(platformRole)) {
      return res.status(403).json({ error: 'Acesso negado para esta função' });
    }
    next();
  };
};

Após criar, aplique nas rotas sensíveis (exemplo):
import { authorize } from '../middleware/authorize';

app.delete('/api/tenants/:id', authenticate, authorize('Owner', 'Admin'), deleteTenant);
app.get('/api/commissions/all', authenticate, authorize('Owner', 'Admin', 'Manager'), getAllCommissions);
