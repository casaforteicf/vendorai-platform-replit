====================================================
5. ENGINE DE REGRAS
====================================================

Criar um motor simples de regras.

Exemplos de regras:

Se objeto.category = Puxador:
- Não permitir trocar por outro tipo se canReplaceObject = false
- Não permitir remover se canRemoveObject = false

Se objeto.category = Marcenaria:
- Não permitir alterar geometria se canChangeGeometry = false
- Não permitir alterar espessura se canChangeGeometry = false

Se objeto.category = Área Vazia / Circulação:
- Não permitir adicionar móveis
- Não permitir preencher com decoração
- Não permitir bloquear fluxo

Se objeto.category = Esquadria:
- Não permitir engrossar perfil
- Não permitir alterar abertura
- Não permitir trocar vidro sem permissão

Se objeto.category = Bancada:
- Não permitir alterar espessura
- Não permitir alterar altura
- Permitir alterar material somente se canChangeMaterial = true

Criar função:
evaluateObjectRules(object)

Retorno:
- allowedActions
- blockedActions
- warnings
- criticalRestrictions

6. PROMPT ENGINE
====================================================

Criar um motor que gere prompt automaticamente a partir da estrutura do projeto.

Funções:
generateCorePrompt(project)
generateProjectPrompt(project)
generateObjectPrompt(project)
generateRulePrompt(project)
generateDNAPrompt(project)
generateRenderPrompt(project)
generateNegativePrompt(project)
generateFinalPrompt(project)

Regras:
- O Core Prompt deve conter preservação absoluta.
- O Object Prompt deve listar objetos importantes e suas permissões.
- O Rule Prompt deve transformar regras em frases de restrição.
- O DNA Prompt deve usar ProjectDNA.
- O Negative Prompt deve ser gerado com base em riscos e permissões bloqueadas.
- O Final Prompt deve unir todos.
