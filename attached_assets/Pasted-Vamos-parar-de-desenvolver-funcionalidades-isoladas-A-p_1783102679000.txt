Vamos parar de desenvolver funcionalidades isoladas.

A partir desta etapa quero reorganizar o arqdor.ai como uma plataforma.

O objetivo não é criar um Prompt Builder.

O objetivo é criar um COPILOT DE ARQUITETURA COM IA.

====================================================

VISÃO DO PRODUTO

O arqdor.ai será o sistema operacional de projetos arquitetônicos assistidos por IA.

O Prompt passa a ser apenas uma saída.

O verdadeiro patrimônio do sistema será o Modelo Inteligente do Projeto.

Toda IA futura consumirá esse modelo.

====================================================
