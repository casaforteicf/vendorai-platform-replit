# COMANDO 15 — Agendamento no Card do Deal + Meet + Lembrete Diário 8h

**Stack:** Node + Drizzle + Supabase · React frontend · Google Calendar OAuth já integrado  
**Objetivo:** (A) agendar reunião/meet direto do card do deal com verificação de disponibilidade, (B) IA pode agendar sozinha, (C) cron diário 8h envia lembrete das agendas do dia para todos os participantes

---

## PARTE A — Botão "Agendar" no card do deal

### Frontend — dentro do card/detalhe do deal no Kanban

Adicionar botão **"📅 Agendar reunião"** no card do deal (junto das ações existentes).

Ao clicar, abrir modal:

```
┌─────────────────────────────────────┐
│ 📅 Agendar com [nome do lead]        │
├─────────────────────────────────────┤
│ Tipo:  ( ) Presencial                │
│        (•) Google Meet               │
│        ( ) Ligação                   │
│                                      │
│ Data:  [date picker]                 │
│                                      │
│ Horários disponíveis:                │
│ [09:00] [10:30] [14:00] [15:30]      │  ← busca da agenda conectada
│                                      │
│ Duração: [30 min ▾]                  │
│                                      │
│ Participantes:                       │
│ ✓ Responsável do deal (auto)         │
│ ✓ Lead (email/WhatsApp do card)      │
│ [+ adicionar participante]           │
│                                      │
│ Observações: [textarea opcional]     │
│                                      │
│ [Cancelar]    [Confirmar agenda]     │
└─────────────────────────────────────┘
```

### Regras dos horários disponíveis

```
1. Buscar eventos do Google Calendar do responsável do deal no dia selecionado
   (google_calendar_token já existe no tenant/usuário)
2. Buscar agendamentos internos da tabela schedules/appointments do mesmo dia
3. Montar slots livres (horário comercial padrão 8h–18h, configurável no tenant)
4. Exibir apenas slots sem conflito
```

### Ao confirmar

```
1. Criar registro em appointments:
   { tenant_id, deal_id, lead_id, responsavel_id, tipo, start_time, end_time,
     meet_link (se tipo=meet), status: 'confirmado', criado_por: 'humano' }
2. Se tipo = Google Meet:
   - Criar evento no Google Calendar via API com conferenceData
     (conferenceDataVersion=1 → gera link do Meet automaticamente)
   - Salvar meet_link retornado
3. Se tipo = Presencial/Ligação: criar evento normal no Calendar
4. Convidar participantes por email (attendees do evento)
5. Enviar WhatsApp de confirmação para o lead:
   "Olá {nome}! Reunião confirmada: {data} às {hora} {via Google Meet: link / presencial: endereço}.
    Até lá! — {nome_empresa}"
6. Criar activity no deal: type='meeting_scheduled'
```

## PARTE B — IA pode agendar sozinha

O Agente Scheduler (já existente no AI Hub) ganha acesso à mesma função de agendamento:

```
1. Expor função interna agendarReuniao({ dealId, leadId, tipo, dataHora, duracao })
   — a MESMA usada pelo modal (não duplicar lógica)
2. Quando o agente estiver conversando com um lead no omnichannel e o lead
   aceitar uma reunião:
   a. Agente consulta slots livres (mesma função de disponibilidade da Parte A)
   b. Oferece 2-3 opções ao lead na conversa
   c. Lead escolhe → agente chama agendarReuniao()
   d. Todo o fluxo da Parte A executa (Calendar + Meet + WhatsApp + activity)
   e. appointments.criado_por = 'agente_ia'
3. Notificar o responsável do deal in-app:
   "🤖 O agente agendou reunião com {lead} para {data} às {hora}"
```

## PARTE C — Lembrete diário às 8h

### Cron job (todo dia às 08:00, timezone America/Sao_Paulo)

```
1. Buscar todos os appointments do dia atual com status = 'confirmado',
   agrupados por tenant
2. Para cada PARTICIPANTE (responsável, lead, participantes extras):

   → RESPONSÁVEL/EQUIPE (via WhatsApp + notificação in-app):
   "☀️ Bom dia, {nome}! Sua agenda de hoje:
    
    🕘 09:00 — Reunião com Ferragem Central (Google Meet) 🔗 {link}
    🕑 14:00 — Visita presencial — Clínica Silva
    🕓 16:30 — Ligação — Loja Moda Fina
    
    Total: 3 compromissos. Boa sorte! — Vendor.ai"

   → LEAD/CLIENTE (via WhatsApp):
   "☀️ Bom dia, {nome}! Lembrete: hoje às {hora} temos {tipo}
    {com link do Meet, se houver}.
    Qualquer imprevisto, é só responder aqui. Até logo! — {nome_empresa}"

3. Se participante não tem WhatsApp → enviar por email (Resend já configurado)
4. Registrar envio em notification_logs para não duplicar
```

### Migration

```sql
CREATE TABLE IF NOT EXISTS appointments (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid REFERENCES tenants(id),
  deal_id uuid REFERENCES deals(id),
  lead_id uuid REFERENCES leads(id),
  responsavel_id uuid REFERENCES users(id),
  tipo text NOT NULL, -- presencial | meet | ligacao
  start_time timestamptz NOT NULL,
  end_time timestamptz NOT NULL,
  meet_link text,
  google_event_id text,
  participantes jsonb DEFAULT '[]', -- [{nome, email, telefone}]
  observacoes text,
  status text DEFAULT 'confirmado', -- confirmado | cancelado | realizado | no_show
  criado_por text DEFAULT 'humano', -- humano | agente_ia
  created_at timestamptz DEFAULT now()
);

CREATE TABLE IF NOT EXISTS notification_logs (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  appointment_id uuid REFERENCES appointments(id),
  recipient text,
  channel text, -- whatsapp | email | in_app
  sent_at timestamptz DEFAULT now()
);
```
