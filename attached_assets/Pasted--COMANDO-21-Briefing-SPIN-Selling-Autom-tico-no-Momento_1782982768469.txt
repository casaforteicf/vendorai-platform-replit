# COMANDO 21 — Briefing SPIN Selling Automático no Momento Certo

**Stack:** Node + Drizzle + Supabase · OpenAI já integrado  
**Conecta com:** cmd-10 (briefing IA do lead), cmd-15 (agendamento + lembretes), cmd-16 (SDR)  
**Objetivo:** a IA gera um briefing SPIN Selling personalizado do lead e entrega ao vendedor NO MOMENTO CERTO — quando a reunião é agendada e reforçado 2h antes dela

---

## PARTE A — Quando o briefing SPIN é gerado (os 2 gatilhos)

```
GATILHO 1 — Reunião agendada (principal)
  Quando: appointment criado (via modal do card OU via agente IA — cmd-15)
  Ação: gerar briefing SPIN do lead vinculado ao deal
  Entrega: notificação in-app + seção no detalhe do deal

GATILHO 2 — Lembrete pré-reunião
  Quando: 2h antes do start_time do appointment
  Ação: enviar resumo do SPIN via WhatsApp ao responsável junto do lembrete
  (integra com o cron do cmd-15 — não criar cron novo)
```

O briefing NÃO é gerado na importação do lead (cedo demais, sem interação)
nem na hora da reunião (tarde demais para preparar). O momento certo é o
agendamento — quando a conversa virou compromisso.

---

## PARTE B — Estrutura do briefing SPIN gerado

### Prompt para a IA (gpt-4o-mini)

```
Você é um coach de vendas especialista em SPIN Selling preparando um vendedor
para uma reunião. Com base nos dados abaixo, gere o roteiro SPIN personalizado.

DADOS DISPONÍVEIS:
- Briefing do negócio: {deals.ai_briefing}           ← cmd-10 (7 seções)
- Avaliações Google: {leads.metadata.reviews}
- Principal reclamação detectada: {principal_reclamacao}
- Histórico de conversa no omnichannel: {últimas 20 mensagens, se houver}
- Activities do deal: {resumo das atividades}
- Tipo de reunião: {appointment.tipo} ({meet|presencial|ligacao})
- Segmento: {vertical} | Cidade: {localidade}

Gere EXATAMENTE nesta estrutura:

## 🎯 CONTEXTO EM 3 LINHAS
Quem é o lead, o que já sabemos, temperatura atual.

## S — PERGUNTAS DE SITUAÇÃO (3)
Perguntas para mapear o cenário atual dele. Específicas ao segmento —
nunca genéricas. Ex: "Quem responde o WhatsApp da loja hoje?"

## P — PERGUNTAS DE PROBLEMA (3)
Perguntas que fazem ELE verbalizar as dores. Baseadas nas reclamações
reais das avaliações. Ex: "Vi clientes comentando demora na resposta —
isso acontece mais em qual horário?"

## I — PERGUNTAS DE IMPLICAÇÃO (3)
Perguntas que ampliam o custo do problema. Ex: "Se 5 clientes por semana
desistem sem resposta, quanto isso dá por mês em venda perdida?"

## N — PERGUNTAS DE NECESSIDADE (2)
Perguntas que fazem ele descrever o valor da solução. Ex: "Se o WhatsApp
respondesse sozinho em 10 segundos, o que mudaria no seu faturamento?"

## ⚠️ ARMADILHAS PREVISTAS
2-3 objeções prováveis DESTE lead específico + resposta de 1 linha para cada.

## 🏁 PRÓXIMO PASSO IDEAL
Qual fechamento buscar nesta reunião (assinar | trial | segunda reunião com sócio).

Seja específico ao negócio. Português brasileiro. Perguntas que soem naturais
faladas em voz alta — não corporativês.
```

### Persistência

```sql
ALTER TABLE appointments ADD COLUMN IF NOT EXISTS spin_briefing text;
ALTER TABLE appointments ADD COLUMN IF NOT EXISTS spin_generated_at timestamptz;
```

## PARTE C — Onde o vendedor vê o briefing

### 1. Detalhe do deal — nova seção (abaixo do briefing IA do cmd-10)

```
┌─────────────────────────────────────┐
│ 🧭 Roteiro SPIN — Reunião 04/07 14h  │
│ Gerado quando a reunião foi marcada  │
├─────────────────────────────────────┤
│ 🎯 Contexto: [3 linhas]              │
│ S · Situação (3 perguntas)       ▾   │
│ P · Problema (3 perguntas)       ▾   │
│ I · Implicação (3 perguntas)     ▾   │
│ N · Necessidade (2 perguntas)    ▾   │
│ ⚠️ Armadilhas previstas          ▾   │
│ 🏁 Próximo passo: [objetivo]         │
│                                      │
│ [🔄 Regenerar] [📋 Copiar] [📱 Enviar│
│  pro meu WhatsApp]                   │
└─────────────────────────────────────┘
```

### 2. WhatsApp 2h antes da reunião (junto do lembrete do cmd-15)

```
"🧭 Preparação — reunião com {lead} às {hora}:

🎯 {contexto resumido em 1 linha}

Comece perguntando:
1. {pergunta S mais forte}
2. {pergunta P mais forte}

Dor principal: {principal_reclamacao}
Cuidado com: {armadilha 1}
Objetivo de hoje: {próximo passo}

Roteiro completo no deal: {link}
Boa reunião! 🚀"
```

(Versão resumida — o WhatsApp não comporta o briefing inteiro; o link leva ao completo)

### 3. Modo apresentação (mobile, para usar DURANTE a reunião)

Botão "▶ Modo reunião" abre o roteiro em tela cheia, uma seção por vez,
com swipe entre S→P→I→N e checkbox por pergunta feita. Fonte grande,
fundo escuro — feito para olhar discretamente no celular durante a conversa.

---

## PARTE D — Regeneração inteligente

```
- Se a reunião for remarcada → NÃO regenerar (mesmo contexto)
- Se houver novas mensagens no omnichannel após a geração → badge
  "💬 Houve conversa nova desde a geração" + botão regenerar
- Regenerar manual sempre disponível (substitui, mantém spin_generated_at novo)
```

---

## VALIDAÇÃO

- [ ] Agendar reunião (humano ou IA) gera o briefing SPIN automaticamente
- [ ] Perguntas P usam as reclamações reais das avaliações Google do lead
- [ ] Seção aparece no detalhe do deal com accordions S/P/I/N
- [ ] 2h antes da reunião o vendedor recebe o resumo no WhatsApp com link
- [ ] Modo reunião funciona em tela cheia no mobile com swipe
- [ ] Reunião remarcada não regenera; conversa nova sugere regenerar
- [ ] "Enviar pro meu WhatsApp" entrega o roteiro completo em mensagens

## AJUSTE — Usar a seção de briefing JÁ EXISTENTE no card do lead

**NÃO criar seção/componente novo.** O card do lead já possui a ferramenta de
briefing IA (implementada no cmd-10). O roteiro SPIN entra DENTRO dela:

```
┌─────────────────────────────────────┐
│ 🤖 Briefing Automático (IA)          │  ← seção já existente
│                                      │
│ [Aba: 📊 Análise] [Aba: 🧭 SPIN]     │  ← adicionar navegação por abas
│                                      │
│ ── Aba Análise (conteúdo atual) ──   │
│ Perfil, reputação, dores, score...   │
│                                      │
│ ── Aba SPIN (novo conteúdo) ──       │
│ Aparece após reunião agendada.       │
│ Antes disso: estado vazio com        │
│ "🧭 O roteiro SPIN será gerado       │
│  quando uma reunião for agendada"    │
│ + botão [Gerar agora] (manual)       │
└─────────────────────────────────────┘
```

Regras:
1. Reaproveitar o componente existente do briefing — adicionar apenas as abas
2. O conteúdo SPIN (accordions S/P/I/N, armadilhas, próximo passo, botões
   Regenerar/Copiar/Enviar WhatsApp/Modo reunião) renderiza dentro da aba SPIN
3. Persistência: manter em appointments.spin_briefing como definido, mas a UI
   busca pelo deal (último appointment futuro do deal)
4. Sem reunião agendada + clique em "Gerar agora" → gera com os dados
   disponíveis e marca origem = 'manual'
5. Cancelar a Parte C item 1 do briefing original (seção separada) —
   substituída por este ajuste. Partes C.2 (WhatsApp 2h antes) e C.3
   (Modo reunião) permanecem inalteradas.
