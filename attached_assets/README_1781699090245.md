# Módulo Site Generator — Vendor.ai

Gera landing pages, e-commerces e sites institucionais com IA (Claude Sonnet),
persiste no Supabase e permite refinamento via chat.

---

## Arquivos entregues

```
supabase/
  001_generated_sites.sql   → SQL para rodar no Supabase SQL Editor

src/pages/SiteGenerator/
  SiteGenerator.jsx         → Componente principal (formulário + preview + chat)
  SiteGenerator.css         → Estilos seguindo identidade do Vendor.ai
  useSiteGenerator.js       → Hook: chamadas à API do Claude + persistência no Supabase
```

---

## Passo 1 — Rodar o SQL no Supabase

1. Abra o projeto **vendorai-core** no Supabase (ref: gfocphuiyyufwzcyihbk)
2. Vá em **SQL Editor → New query**
3. Cole o conteúdo de `supabase/001_generated_sites.sql` e clique em **Run**

Isso cria a tabela `generated_sites` com:
- `tenant_id` (multi-tenant, FK para a tabela `tenants`)
- `site_type` (landing | ecommerce | institutional)
- `config` (JSON com os dados do formulário)
- `html` (HTML completo gerado pelo Claude)
- RLS ativado (cada tenant só vê os próprios sites)

---

## Passo 2 — Copiar os arquivos no Replit

No projeto **vendorai-core** no Replit:

1. Abra o painel de arquivos (ícone de pasta na sidebar)
2. Navegue até `src/pages/`
3. Crie a pasta `SiteGenerator/`
4. Crie os 3 arquivos dentro dela:
   - `SiteGenerator.jsx` (cole o conteúdo)
   - `SiteGenerator.css` (cole o conteúdo)
   - `useSiteGenerator.js` (cole o conteúdo)

---

## Passo 3 — Adicionar a rota no App.jsx (ou no arquivo de rotas)

Abra o arquivo que define as rotas do vendorai-core e adicione:

```jsx
import SiteGenerator from './pages/SiteGenerator/SiteGenerator.jsx'

// dentro do <Routes>:
<Route
  path="/site-generator"
  element={
    <SiteGenerator
      supabase={supabaseClient}
      tenantId={currentTenantId}
    />
  }
/>
```

Substitua `supabaseClient` e `currentTenantId` pelas variáveis que você já
usa nas outras rotas do vendorai-core.

---

## Passo 4 — Adicionar ao menu de navegação

No componente de menu/sidebar do vendorai-core, adicione um item:

```jsx
{ path: '/site-generator', label: 'Gerador de Sites', icon: 'Globe' }
```

---

## Como funciona

```
Usuário preenche formulário
        ↓
useSiteGenerator.generate(config)
        ↓
POST https://api.anthropic.com/v1/messages
  model: claude-sonnet-4-6
  prompt: SPIN Selling + dados do negócio
        ↓
HTML completo retornado
        ↓
Renderizado no <iframe srcdoc={html}>
        ↓
Salvo em generated_sites no Supabase
        ↓
Chat de refinamento (mantém histórico de mensagens)
        ↓
Download do .html ou publicação futura
```

---

## Props do componente

| Prop | Tipo | Descrição |
|------|------|-----------|
| `supabase` | objeto | Cliente Supabase já instanciado (pode ser null para funcionar sem persistência) |
| `tenantId` | string uuid | ID do tenant atual (para isolamento multi-tenant) |

---

## Notas técnicas

- A API key do Claude não precisa ser passada no frontend — o proxy já
  lida com isso (mesma configuração usada pelos agentes do AI Hub).
- O hook `useSiteGenerator` é independente do componente de UI —
  pode ser reutilizado em outros módulos do Vendor.ai.
- O HTML gerado é autocontido (HTML + CSS + JS em um arquivo) —
  pode ser hospedado em qualquer lugar ou entregue diretamente ao cliente.
