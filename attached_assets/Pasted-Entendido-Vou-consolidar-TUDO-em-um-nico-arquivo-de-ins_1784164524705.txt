🔍 DIAGNÓSTICO ATUAL (RESUMO)

O Prospector atual:

· Fontes: Google Places + BrasilAPI + CNPJá + Meta Ad Library + Digital Scanner
· Scoring: Heurístico simples (pontua por presença de telefone/website/rating) + IA (GPT-4o-mini) para análise preditiva
· Problemas:
  · ❌ Sem loop de feedback (vendedores não avaliam leads)
  · ❌ Sem memória de qualificação (não aprende com leads convertidos)
  · ❌ Score heurístico fraco (não pondera sinais de crescimento)
· Tabelas: prospector_config, prospector_queue, leads, deals

🚀 MELHORIAS PROPOSTAS

1. Loop de Feedback — Vendedores avaliam leads (1 a 5) e isso ajusta os pesos do scoring dinamicamente.
2. Memória com Embeddings — Usar pgvector para comparar novos prospects com leads que converteram (similaridade semântica).
3. Score Heurístico Aprimorado — Pesos ajustáveis por feedback + bônus de similaridade.

  industry TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Adicionar coluna de quality_score na tabela leads (se não existir)

// src/agents/prospector-feedback.ts
import { db } from '../db';
import { prospect_feedback, leads, prospector_config } from '../schema';
import { eq, and, desc, sql } from 'drizzle-orm';

// 1. Registrar feedback de um lead
export const registerFeedback = async (leadId: number, userId: number, rating: number, comment?: string) => {
  await db.insert(prospect_feedback).values({
    lead_id: leadId,
    user_id: userId,
    rating: rating,
    comment: comment,
    converted: false,
  });

  // Atualiza o lead com o rating médio
  const avgRating = await db
    .select({ avg: sql<number>`avg(rating)` })
    .from(prospect_feedback)
    .where(eq(prospect_feedback.lead_id, leadId));
  
  await db.update(leads)
    .set({ quality_score: avgRating[0]?.avg || 0 })
    .where(eq(leads.id, leadId));

  console.log(`[FEEDBACK] Lead ${leadId} avaliado com ${rating}/5`);
};

// 2. Marcar que um lead virou cliente (conversão)
export const markConverted = async (leadId: number) => {
  await db.update(prospect_feedback)
    .set({ converted: true })
    .where(eq(prospect_feedback.lead_id, leadId));
  
  console.log(`[FEEDBACK] Lead ${leadId} marcado como convertido.`);
};

// 3. Ajustar os pesos do scoring com base no feedback histórico
export const getAdjustedWeights = async (tenantId: string) => {
  const feedbacks = await db.select({
    lead_id: prospect_feedback.lead_id,
    rating: prospect_feedback.rating,
    converted: prospect_feedback.converted,
  })
  .from(prospect_feedback)
  .innerJoin(leads, eq(leads.id, prospect_feedback.lead_id))
  .where(eq(leads.tenant_id, tenantId));

  if (feedbacks.length < 10) {
    console.log('[FEEDBACK] Poucos dados, usando pesos padrão.');
    return getDefaultWeights();
  }

  // Análise simplificada: leads com rating >= 4 e convertidos = "bons"
  const goodLeads = feedbacks.filter(f => f.rating >= 4 && f.converted);
  const badLeads = feedbacks.filter(f => f.rating <= 2);

  // Ajuste dinâmico (exemplo: aumentar peso de "active_ads" se bons leads tinham anúncio)
  return {
    has_phone: 15,
    has_website: 10,
    rating_google: goodLeads.length > 0 ? 25 : 20,
    active_ads: goodLeads.length > 0 ? 30 : 15,
    recent_opening: 15,
    has_crm: 15,
  };
};

const getDefaultWeights = () => ({
  has_phone: 10,
  has_website: 10,
  rating_google: 20,
  active_ads: 15,
  recent_opening: 10,
  has_crm: 10,
});
```

// src/agents/prospector-embeddings.ts
import { db } from '../db';
import { lead_embeddings, leads } from '../schema';
import { eq, desc, sql } from 'drizzle-orm';
import OpenAI from 'openai';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

// 1. Gerar embedding de um lead (usa OpenAI ada-002)
export const generateLeadEmbedding = async (lead: any) => {
  const text = `
    Empresa: ${lead.company}
    Setor: ${lead.industry || ''}
    Descrição: ${lead.description || ''}
    Produtos/Serviços: ${lead.products || ''}
    Porte: ${lead.size || ''}
  `;
  const response = await openai.embeddings.create({
    model: 'text-embedding-ada-002',
    input: text,
  });
  return response.data[0].embedding;
};

// 2. Armazenar embedding de um lead que converteu
export const storeConvertedLeadEmbedding = async (leadId: number) => {
  const lead = await db.select().from(leads).where(eq(leads.id, leadId)).limit(1);
  if (!lead[0]) return;

  const embedding = await generateLeadEmbedding(lead[0]);
  await db.insert(lead_embeddings).values({
    lead_id: leadId,
    embedding: embedding,
    company_name: lead[0].company,
    industry: lead[0].industry,
  });
};

// 3. Comparar novo prospect com leads convertidos (similaridade)
export const compareWithConverted = async (prospect: any): Promise<number> => {
  const convertedEmbeddings = await db
    .select()
    .from(lead_embeddings)
    .orderBy(desc(lead_embeddings.created_at))
    .limit(100);

  if (convertedEmbeddings.length === 0) return 0;

  const newEmbedding = await generateLeadEmbedding(prospect);

  // Calcula similaridade com cada embedding
  const similarities = await Promise.all(convertedEmbeddings.map(async (ref) => {
    const result = await db
      .select({ similarity: sql<number>`1 - (${newEmbedding} <=> ${ref.embedding})` })
      .from(lead_embeddings)
      .where(eq(lead_embeddings.id, ref.id))
      .limit(1);
    return result[0]?.similarity || 0;
  }));

  const avg = similarities.reduce((a, b) => a + b, 0) / similarities.length;
  return Math.round(avg * 100);
};
```

```typescript
// src/agents/prospector-orchestrator.ts
import OpenAI from 'openai';
import { fetchNextProspect, markProspectProcessed, createLeadFromProspect, prospectorToolSchemas } from './prospector-tools';
import { getAdjustedWeights } from './prospector-feedback';
import { compareWithConverted } from './prospector-embeddings';
import { db } from '../db';
import { prospector_config } from '../schema';
import { eq } from 'drizzle-orm';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export const runProspector = async (tenantId: string) => {
  console.log('[PROSPECTOR] Iniciando com inteligência aprimorada...');

  const prospect = await fetchNextProspect(tenantId);
  if (!prospect) return;

  // 1. Busca pesos ajustados pelo feedback
  const weights = await getAdjustedWeights(tenantId);

  // 2. Calcula similaridade com leads convertidos
  const similarityScore = await compareWithConverted(prospect);

  // 3. Monta prompt com pesos e similaridade
  const systemPrompt = `
Você é especialista em prospecção B2B da VendorAI.
Avalie este prospect com os seguintes pesos:

- Tem telefone: ${weights.has_phone} pts
- Tem website: ${weights.has_website} pts
- Rating Google > 4.0: ${weights.rating_google} pts
- Possui anúncios ativos: ${weights.active_ads} pts
- Empresa recém-aberta (< 2 anos): ${weights.recent_opening} pts
- Possui CRM: ${weights.has_crm} pts

Similaridade com leads convertidos: ${similarityScore}%.

Dados:
Empresa: ${prospect.company_name}
Website: ${prospect.website || 'N/A'}
Setor: ${prospect.industry || 'N/A'}
Google Rating: ${prospect.google_rating || 'N/A'}
Anúncios ativos: ${prospect.has_ads ? 'Sim' : 'Não'}
Recém-aberta: ${prospect.is_recent ? 'Sim' : 'Não'}
Possui CRM: ${prospect.has_crm ? 'Sim' : 'Não'}

Use a ferramenta "qualifyProspect" com score 0-100. Considere bônus de até 10% pela similaridade.`;

  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      { role: 'system', content: systemPrompt },
      { role: 'user', content: 'Analise este prospect.' }
    ],
    tools: prospectorToolSchemas,
    tool_choice: { type: 'function', function: { name: 'qualifyProspect' } },
    temperature: 0.2,
  });

  const toolCall = response.choices[0].message.tool_calls?.[0];
  if (!toolCall) {
    await markProspectProcessed(prospect.id, 'error', { error: 'No tool call' });
    return;
  }

  const args = JSON.parse(toolCall.function.arguments);
  console.log(`[PROSPECTOR] Score: ${args.score} - ${args.reason}`);

  // Threshold ajustado
  const config = await db.select().from(prospector_config).where(eq(prospector_config.tenant_id, tenantId));
  const threshold = config[0]?.auto_dispatch_threshold || 80;
  const adjustedThreshold = threshold - (similarityScore > 50 ? 5 : 0);

  if (args.should_create_lead && args.score >= adjustedThreshold) {
    const lead = await createLeadFromProspect(prospect);
    if (args.score > 90) {
      await db.update(leads).set({ stage: 'Qualificado' }).where(eq(leads.id, lead.id));
    }
    await markProspectProcessed(prospect.id, 'qualified', args);
  } else {
    await markProspectProcessed(prospect.id, 'discarded', args);
    console.log('[PROSPECTOR] Descartado (abaixo do threshold).');
  }
};
```

📂 ARQUIVO: src/routes/feedback.ts (Nova rota para avaliação)

```typescript
// src/routes/feedback.ts
import express from 'express';
import { registerFeedback, markConverted } from '../agents/prospector-feedback';
import { authenticate } from '../middleware/auth';

const router = express.Router();

router.post('/api/feedback/lead', authenticate, async (req, res) => {
  try {
    const { leadId, rating, comment } = req.body;
    if (!leadId || !rating || rating < 1 || rating > 5) {
      return res.status(400).json({ error: 'leadId e rating (1-5) são obrigatórios' });
    }
    await registerFeedback(leadId, req.user.id, rating, comment);
    res.json({ success: true });
  } catch (error) {
    console.error('[FEEDBACK] Erro:', error);
    res.status(500).json({ error: 'Internal error' });
  }
});

router.post('/api/feedback/convert', authenticate, async (req, res) => {
  try {
    const { leadId } = req.body;
    await markConverted(leadId);
    res.json({ success: true });
  } catch (error) {
    console.error('[FEEDBACK] Erro:', error);
    res.status(500).json({ error: 'Internal error' });
  }
});

export default router;
```
