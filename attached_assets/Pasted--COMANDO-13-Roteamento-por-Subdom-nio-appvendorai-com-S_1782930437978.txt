# COMANDO 13 — Roteamento por Subdomínio (appvendorai.com)

**Stack:** Node + Express + Drizzle · React + Vite frontend  
**Contexto:** appvendorai.com já está verificado no Replit. O wildcard *.appvendorai.com resolve via Cloudflare. Tenants já têm campo subdomain gerado no onboarding. Falta o backend rotear pelo host.  
**Problema:** wolmann-design.appvendorai.com retorna ERR_CONNECTION_CLOSED

---

## Parte A — Middleware de resolução de tenant por host

No arquivo principal do servidor (server/index.ts ou app.ts), adicionar middleware ANTES de todas as rotas:

```javascript
async function tenantByHostMiddleware(req, res, next) {
  const host = req.headers.host ?? '';
  
  // Ignorar domínios principais — não aplicar resolução de tenant
  const mainDomains = [
    'vendorai.replit.app',
    'appvendorai.com',
    'www.appvendorai.com',
    'localhost',
    '127.0.0.1'
  ];
  
  const isMainDomain = mainDomains.some(d => host === d || host.startsWith(d + ':'));
  if (isMainDomain) return next();

  // Extrair subdomínio: "wolmann-design.appvendorai.com" → "wolmann-design"
  const subdomain = host.split('.')[0];
  if (!subdomain) return next();

  // Buscar tenant pelo subdomínio OU domínio customizado
  const tenant = await db.query.tenants.findFirst({
    where: or(
      eq(tenants.subdomain, subdomain),
      eq(tenants.custom_domain, host)
    )
  });

  if (!tenant) {
    return res.status(404).json({ error: 'Tenant não encontrado', subdomain });
  }

  if (tenant.status === 'blocked') {
    return res.status(402).json({ error: 'Acesso suspenso por inadimplência' });
  }

  // Injetar tenant no request para uso nas rotas
  req.tenantId = tenant.id;
  req.tenant = tenant;
  next();
}

// Aplicar antes de todas as rotas
app.use(tenantByHostMiddleware);
```

## Parte B — Frontend: servir o app para subdomínios

O Vite/React precisa ser servido também quando o host é um subdomínio. No handler de catch-all do servidor (que serve o index.html), garantir que subdomínios também recebem o frontend:

```javascript
// Rota catch-all — serve o React app para qualquer rota não-API
app.get('*', (req, res) => {
  res.sendFile(path.join(__dirname, '../client/dist/index.html'));
});
```

## Parte C — Frontend: detectar subdomínio e ajustar contexto

No React (App.tsx ou um Provider), detectar se está em subdomínio e passar o tenant como contexto:

```javascript
// hooks/useTenantFromHost.ts
export function useTenantFromHost() {
  const host = window.location.hostname;
  const mainDomains = ['vendorai.replit.app', 'appvendorai.com', 'localhost'];
  const isMain = mainDomains.some(d => host === d || host.endsWith('.' + d) === false);
  
  if (isMain) return null;
  
  // Subdomínio detectado — o backend já resolve via middleware
  // Frontend apenas sabe que está em modo "tenant subdomain"
  return host.split('.')[0];
}
```

## Parte D — Migration

```sql
ALTER TABLE tenants ADD COLUMN IF NOT EXISTS subdomain text UNIQUE;
ALTER TABLE tenants ADD COLUMN IF NOT EXISTS custom_domain text UNIQUE;
ALTER TABLE tenants ADD COLUMN IF NOT EXISTS custom_domain_status text DEFAULT 'not_configured';

-- Gerar subdomínio para tenants existentes que não têm
UPDATE tenants 
SET subdomain = lower(regexp_replace(name, '[^a-zA-Z0-9]', '-', 'g'))
WHERE subdomain IS NULL;
```
