# Briefing — Conectar Comentários do Instagram ao CRM (fechar o ciclo)

**Como usar:** envie cada "Passo" como mensagem separada pro Replit Agent, um de cada vez, esperando terminar antes do próximo.

**Objetivo:** quando alguém comenta uma palavra-chave (ex: "PROSPECT", "IA", "QUERO") num post, isso vira lead automaticamente no CRM e o agente SDR assume a conversa — sem você precisar ver e responder na mão.

---

## Passo 1 — Diagnóstico
```
Me mostre o estado atual da integração com Instagram via Meta Cloud API:
1. Hoje já recebemos webhook de comentários em posts, ou só de mensagens diretas (DM)?
2. Se já recebemos comentários, onde esse dado chega no sistema hoje?
3. Como funciona a criação de um lead novo no CRM hoje — que agente ou rota é acionada?

Não altere nada ainda, só me traga esse diagnóstico.
```

## Passo 2 — Capturar comentários com palavra-chave
```
Configure o webhook do Instagram (via Meta Cloud API) para escutar comentários em posts, se ainda não escutar. Quando um comentário contiver uma das palavras-chave configuradas (ex: "PROSPECT", "IA", "QUERO" — deixe essa lista editável, não fixa no código), capture:
- Nome/usuário de quem comentou
- Texto do comentário
- Qual post gerou o comentário
- Data/hora
```

## Passo 3 — Criar o lead automaticamente
```
Quando um comentário com palavra-chave for capturado (Passo 2), crie um lead novo no CRM automaticamente com:
- Origem: "Instagram - comentário"
- Nome: usuário do Instagram
- Contexto: texto do comentário + qual post
- Status inicial: "Novo"

Use a mesma estrutura/tabela de leads que já existe hoje — não crie uma tabela paralela.
```

## Passo 4 — Acionar o agente SDR
```
Assim que o lead for criado (Passo 3), acione o agente SDR automaticamente pra iniciar contato — da mesma forma que ele já faz hoje com leads vindos de outras origens (ex: Prospector). Se o Instagram do lead permitir DM automática, inicia por lá; senão, deixa o lead na fila do SDR pra abordagem manual assistida.
```

## Passo 5 — Teste real
```
Simule um comentário de teste com a palavra-chave "PROSPECT" num post de teste e confirme:
1. O lead foi criado no CRM com a origem correta
2. O agente SDR foi acionado
3. Nenhum dado real de cliente foi usado no teste

Me mostre o resultado (print do lead criado + status do SDR) antes de considerar isso pronto.
```
