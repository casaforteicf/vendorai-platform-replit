# Briefing — Ajuste do Instagram Content Studio (Vendor.ai)

**Objetivo geral:** transformar o gerador atual (tema → N imagens soltas) em um fluxo que sabe para qual formato está gerando (Feed/Stories/Reels), permite importar múltiplas imagens do cliente, e automatiza texto + música em Reels.

Colar cada passo separadamente no Replit Agent, na ordem abaixo. Cada passo é independente e testável antes de avançar para o próximo.

---

## Passo 1 — Corrigir copy e layout mobile

No módulo Instagram Content Studio (`/api/content-studio` e componente correspondente no front):

1. Trocar o texto "Preencha o tema ao lado e clique em Gerar com IA" por "Preencha o tema acima e toque em Gerar com IA" (o layout mobile é empilhado verticalmente, não tem coluna lateral).
2. Revisar o componente para garantir que em telas <768px o formulário e o preview fiquem em ordem vertical lógica: formato → tema → quantidade → referência → botão gerar → preview.
3. Não alterar lógica de geração neste passo, só copy e ordenação visual.

---

## Passo 2 — Seletor de formato de destino (Feed / Stories / Reels)

Adicionar um seletor obrigatório no topo do formulário, antes de "Quantidade de imagens":

**Opções:** Feed (1:1 ou 4:5), Stories (9:16), Reels (9:16, vídeo)

Regras de negócio:
- Feed: permite escolher 1:1 ou 4:5 (toggle secundário), quantidade de imagens 1/2/4/6/8/10 continua como está hoje.
- Stories: força aspect ratio 9:16, quantidade sugerida 1 (mas permite até 10 para carrossel de stories sequenciais).
- Reels: força 9:16, desabilita "quantidade de imagens" (Reels é vídeo único) e habilita os campos novos do Passo 4 e Passo 5 (texto automático e trilha sonora).

Schema (Drizzle): adicionar campo `content_format` (enum: `feed_square`, `feed_portrait`, `stories`, `reels`) e `aspect_ratio` na tabela de geração de conteúdo do Content Studio. Persistir a escolha para reaproveitar nas próximas gerações do mesmo tenant.

Ajustar o prompt enviado para geração de imagem (DALL-E/Claude) para incluir a proporção correta conforme o formato escolhido.

---

## Passo 3 — Importar múltiplas imagens do cliente

Substituir o campo atual "Imagem de referência do cliente (opcional)" — que hoje aceita só 1 imagem — por um uploader múltiplo:

1. Permitir upload de N imagens (sem limite artificial baixo; sugestão: até 20 por sessão, 10MB cada, JPG/PNG/WebP).
2. Cada imagem importada aparece como thumbnail numa grade, com opção de remover individualmente.
3. Adicionar toggle "Usar como referência de estilo" vs "Usar como material para postar" — isso define se a imagem serve só de inspiração para a IA gerar algo novo, ou se vai direto para edição/postagem sem gerar imagem nova.
4. Se "material para postar": abrir um editor simples por imagem (crop conforme aspect ratio do formato escolhido no Passo 2, texto sobreposto opcional, filtro/ajuste básico).

Schema: nova tabela `content_studio_uploads` (id, tenant_id, session_id, file_url, purpose enum: `style_reference` | `post_material`, created_at).

---

## Passo 4 — Texto automático em Reels

Quando formato = Reels, habilitar geração automática de overlay de texto no vídeo:

1. Campo de texto (headline curta, ex: nome do produto/promoção) + seletor de posição (topo/centro/rodapé) + template visual (2-3 estilos prontos: institucional, promocional, urgência).
2. Pipeline de composição: usar ffmpeg (via `drawtext` filter) ou Remotion para renderizar o overlay sobre o vídeo gerado, antes do MP4 final.
3. O overlay deve ser gerado automaticamente a partir do tema informado se o usuário não preencher manualmente (usar Claude para sugerir headline curta a partir do tema/produto).

Endpoint novo: `POST /api/content-studio/reels/render` — recebe vídeo base + texto + posição, retorna MP4 final com overlay embutido.

---

## Passo 5 — Trilha sonora automática em Reels

**Restrição importante a respeitar:** a API do Instagram não permite anexar músicas do catálogo/biblioteca nativa do Instagram via publicação programática — isso só é possível manualmente dentro do app. Não tentar integrar com a biblioteca de músicas do Instagram.

Caminho correto: embutir a trilha diretamente no arquivo de vídeo antes do upload.

1. Criar/curar um banco próprio de trilhas royalty-free por "vibe" (institucional, promocional, urgência, calma/premium) — pode começar com um catálogo licenciado pequeno (5-10 faixas) armazenado no Supabase Storage.
2. No formulário de Reels, adicionar seletor "Trilha sonora" com preview de áudio (play curto de 5s) e as opções de vibe.
3. No mesmo pipeline do Passo 4 (ffmpeg/Remotion), mixar a trilha escolhida no áudio do vídeo final, respeitando volume ajustável (para não sobrepor narração, se houver, ex: vídeos gerados via HeyGen).
4. Persistir a trilha escolhida associada à geração para reuso/histórico.

Schema: tabela `content_studio_audio_tracks` (id, name, vibe enum, file_url, license_info, duration_seconds).

---

## Passo 6 — Testes e validação

1. Testar geração completa para os 4 formatos (Feed 1:1, Feed 4:5, Stories, Reels) e confirmar que o aspect ratio bate com o exigido pela Graph API do Instagram (Feed: 4:5 a 1.91:1; Stories/Reels: 9:16 recomendado).
2. Testar upload múltiplo de imagens do cliente (mínimo 5 imagens simultâneas) e confirmar que cada uma pode ser editada/removida individualmente.
3. Testar Reels completo: overlay de texto + trilha sonora embutidos no MP4 final, publicação via API confirmando que o áudio chega junto (sem depender da biblioteca nativa do Instagram).
4. Confirmar que o limite de publicação da API (100 posts/24h por conta) está sendo respeitado no fluxo de agendamento.
