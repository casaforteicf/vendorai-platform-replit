# Embedded Signup

Implementar Embedded Signup da Meta.

Criar:

GET /api/auth/whatsapp

GET /api/auth/whatsapp/callback

Fluxo:

1. Cliente clica em "Conectar WhatsApp"
2. Meta Embedded Signup abre
3. Cliente seleciona ou cria conta WhatsApp Business
4. Sistema recebe:

   * WABA_ID
   * PHONE_NUMBER_ID
   * ACCESS_TOKEN
5. Salvar conexão automaticamente

# Webhooks

Criar endpoint:

POST /api/webhooks/meta/whatsapp

Validar:

hub.mode
hub.verify_token
hub.challenge

Eventos suportados:

* messages
* message_status
* message_template_status
* phone_number_quality_update

Salvar todos os eventos recebidos.
