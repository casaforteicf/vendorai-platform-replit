FEATURE: AI SALES AGENT + ORÇAMENTO AUTOMÁTICO
Objetivo

Implementar um módulo chamado AI Sales Agent responsável por:

Receber leads do WhatsApp Cloud API.
Entender a necessidade do cliente usando OpenAI.
Identificar produtos, quantidades e especificações.
Consultar estoque no PostgreSQL.
Solicitar informações faltantes.
Gerar orçamento automaticamente.
Gerar PDF profissional.
Enviar PDF pelo WhatsApp.
Registrar tudo no CRM.
Atualizar pipeline de vendas.

OPENAI SERVICE

Criar serviço:

AiLeadUnderstandingService

Responsável por:

Receber mensagens do cliente.

Extrair JSON estruturado.

Formato obrigatório:

{
"intent":"quote_request",
"category":"pvc_windows",
"products":[
{
"name":"",
"quantity":0,
"width":"",
"height":"",
"color":""
}
],
"missing_information":[]
}

Nunca retornar texto livre.

Sempre retornar JSON.

Usar response_format json_schema.

Modelo:

gpt-4o-mini
