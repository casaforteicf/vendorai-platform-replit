## PARTE A — Migração do motor de render

### Estratégia por função

| Função | Motor | Motivo |
|---|---|---|
| Render principal (preservação) | **Flux + ControlNet via Replicate** | Preservação por estrutura, não por prompt |
| Inpainting de material (máscara SAM) | Flux inpainting via Replicate (fallback: gpt-image-1 images.edit) | Mais controle na região |
| Sugestões de decoração | gpt-image-1 (manter como está) | Criatividade desejada, já funciona |
| Segmentação por clique | SAM via Replicate (cmd-19) | — |

### Implementação no ai-gateway.ts

```
1. Adicionar provider 'replicate' ao gateway existente (não quebrar OpenAI)
2. Secret: REPLICATE_API_TOKEN
3. Modelo render principal:
   "black-forest-labs/flux-canny-pro" (ControlNet canny embutido) OU
   "black-forest-labs/flux-depth-pro" — testar os dois, canny tende a ser
   melhor para linhas arquitetônicas retas
4. Parâmetros travados:
   { guidance: 30, steps: 50, control_strength: 0.75 (canny) }
5. Fallback automático: se Replicate falhar → gpt-image-1 (fluxo atual)
   + log em automation_logs { flow: 'render_fallback' }
6. Prompt: manter as ABSOLUTE PRESERVATION RULES existentes (auditoria §3.1)
   como reforço — agora com a trava estrutural do ControlNet por baixo
```

## PARTE B — Redesign CLEAN da tela de render

### Princípios
- Tela dividida em 2 áreas apenas: **imagem grande à esquerda (75%)** + **painel único à direita (25%)**
- Eliminar as 3 barras empilhadas atuais (ConfigBar + MaterialBar + BottomBar) — tudo vira seções colapsáveis do painel direito
- Imagem é a protagonista: canvas ocupa a altura toda, fundo escuro neutro
- Máximo 1 accent color (violeta da marca) — remover excesso de chips coloridos

### Layout novo

```
┌──────────────────────────────────┬──────────────────┐
│                                  │ 🖼 PROJETO         │
│                                  │ [nome] [trocar]   │
│                                  ├──────────────────┤
│                                  │ 1 · AMBIENTE   ▾  │
│        IMAGEM / CANVAS           │ (9 tipos, grid)   │
│      (75% da largura,            │ 2 · ESTILO     ▾  │
│       altura total,              │ (6 estilos)       │
│       zoom + pan)                │ 3 · ILUMINAÇÃO ▾  │
│                                  │ (6 chips: +nublado│
│  [🎯 Selecionar] [↔ Antes/Depois]│ 4 · ÂNGULO     ▾  │
│                                  │ 5 · COMPONENTES ▾ │
│                                  │ (painel do cmd-19)│
│                                  ├──────────────────┤
│                                  │ Observações       │
│                                  │ [textarea 1 linha]│
│                                  │ ┌──────────────┐  │
│                                  │ │ ✨ GERAR      │  │
│                                  │ │   RENDER      │  │
│                                  │ └──────────────┘  │
│                                  │ 🔒 Preserva 100%  │
├──────────────────────────────────┴──────────────────┤
│ 🕐 HISTÓRICO: [thumb] [thumb] [thumb] [thumb] →      │
└─────────────────────────────────────────────────────┘
```

### Detalhes de execução
- Seções do painel são accordions — só uma aberta por vez, estado inicial: Ambiente
- Seleção feita → accordion colapsa mostrando o valor escolhido no header
  ("1 · AMBIENTE — Cozinha ✓")
- Materiais saem da barra inferior → viveem dentro de "5 · COMPONENTES"
  (aplicação via clique/drag do cmd-19)
- Slider Antes/Depois sobre a imagem (padrão Redraw) após cada render
- Mobile: painel vira bottom-sheet deslizável, imagem em cima
- Histórico horizontal de thumbnails no rodapé — clique restaura o render
- Loading do render: skeleton com progresso sobre a própria imagem
  (não spinner genérico)
