# Briefing — Redesenho do módulo de Vídeo com IA (Content Studio)

**Objetivo geral:** substituir o formulário linear atual (script → upload de avatar → accordion escondido do HeyGen) por uma home de vídeo em grid de cards, cada um abrindo um fluxo dedicado com padrão de duas abas + painel de resultado + barra de ações fixa — inspirado no HeyGen, mas curado só com o que faz sentido pro caso de uso do Vendor.ai (vídeos de venda/marketing pra PMEs).

Colar cada passo separadamente no Replit Agent, na ordem abaixo. Cada passo é independente e testável antes de avançar.

---

## Passo 1 — Nova home de vídeo (grid de cards)

Criar uma sub-seção "Vídeo com IA" dentro do Content Studio (pode ser uma nova aba ao lado de "Script com IA" e "Vídeo de Produto", ou substituir a seção accordion atual).

Layout: grid de cards (3 colunas desktop, 1 coluna mobile), cada card com imagem/gradiente de fundo, título e CTA. Cards a incluir nesta primeira leva (curado, não copiar os 12+ do HeyGen):

1. **Avatar falando** — gera vídeo com avatar (via script ou foto) narrando o conteúdo
2. **Vídeo de Produto** — já existe, só reposicionar como card
3. **Edição automática** — cliente sobe vídeo bruto, IA corta/edita e remove silêncios/palavras indesejadas
4. **Clipes automáticos** — vídeo longo → cortes curtos pra Reels/Stories (equivalente ao "Highlights Instantâneos")
5. **Vídeo em lote** — gera vários vídeos de avatar de uma vez a partir de uma planilha (útil pra campanhas com múltiplos leads/produtos)

Cada card leva para uma rota própria (`/content-studio/video/avatar`, `/content-studio/video/edicao`, etc.), não para uma seção expansível na mesma página.

Schema: nenhuma mudança ainda, só roteamento e componentes de UI.

---

## Passo 2 — Padrão de tela para cada fluxo (duas abas + painel duplo)

Para cada card do Passo 1, aplicar o mesmo padrão de layout (baseado no fluxo "Avatar" do HeyGen):

**Estrutura da tela:**
- Cabeçalho com título curto e descrição de uma linha
- Painel duplo lado a lado (empilhado no mobile):
  - **Coluna esquerda:** input de conteúdo, com abas alternáveis quando fizer sentido (ex: "Roteiro para vídeo" vs "Foto para vídeo" no fluxo de Avatar)
  - **Coluna direita:** área de upload/preview (drag-and-drop, com exemplos/amostras clicáveis abaixo pra facilitar teste rápido)
- **Barra de ações fixa no rodapé do painel:** seletor de voz, qualidade de saída (720p/1080p), configurações avançadas (ícone), botão "Gerar" destacado à direita

Componente reutilizável: criar um `VideoGenPanel` genérico que recebe props (abas disponíveis, tipo de upload aceito, opções da barra de ações) para não duplicar layout em cada fluxo.

---

## Passo 3 — Fluxo "Avatar falando" (script ou foto)

Implementar a tela conforme padrão do Passo 2:

- Aba "Roteiro para vídeo": campo de texto para script (com botão de gerar automaticamente a partir do tema, reaproveitando a geração de script que já existe hoje).
- Aba "Foto para vídeo": upload de foto do avatar (mín. 720p, rosto visível) — reaproveita o upload de vídeo/avatar que já existe, mas adaptado pra aceitar foto estática também, já que o HeyGen anima a partir de foto.
- Barra de ações: seletor de voz (integrar vozes disponíveis via API do HeyGen), qualidade, botão Gerar.

Endpoint: `POST /api/content-studio/video/avatar` — recebe `script` OU `photo_url`, `voice_id`, `quality`, retorna job_id para polling de status (geração de vídeo é assíncrona).

---

## Passo 4 — Fluxo "Edição automática" e "Clipes automáticos"

Dois fluxos simples de upload + processamento:

**Edição automática:**
- Upload de vídeo bruto (MP4/MOV)
- IA remove silêncios e palavras de preenchimento automaticamente
- Preview do resultado antes de confirmar

**Clipes automáticos:**
- Upload de vídeo longo (ex: gravação de obra, depoimento de cliente)
- IA identifica os melhores trechos e gera 2-4 clipes curtos (9:16, prontos pra Reels/Stories)
- Cada clipe gerado aparece como card individual com preview e botão "usar este clipe" (que leva direto pro Passo 4/5 do briefing anterior — overlay de texto + trilha sonora)

Endpoints: `POST /api/content-studio/video/edit-auto` e `POST /api/content-studio/video/clips-auto`, ambos assíncronos com polling.

---

## Passo 5 — Fluxo "Vídeo em lote"

Caso de uso: gerar vários vídeos de avatar de uma vez, um por lead/produto (ex: 20 vídeos personalizados de prospecção, cada um citando o nome da empresa-alvo).

1. Upload de planilha (CSV/XLSX) com colunas: nome do destinatário, variável de script (ex: nome da empresa, produto de interesse).
2. Script-base com placeholders (ex: "Olá {{nome_empresa}}, temos uma solução pra vocês...").
3. Sistema gera um job por linha da planilha, usando o mesmo avatar/voz configurados.
4. Tela de acompanhamento mostrando progresso de cada vídeo (fila, processando, pronto, erro).

Esse fluxo conecta diretamente com o Prospector — os vídeos gerados podem ser anexados automaticamente às mensagens de cold outreach do agente SDR.

Schema: tabela `content_studio_batch_jobs` (id, tenant_id, template_script, avatar_id, voice_id, status, created_at) e `content_studio_batch_items` (id, batch_job_id, recipient_data jsonb, video_url, status).

---

## Passo 6 — Testes e validação

1. Testar navegação: home em grid → cada card abre sua rota própria sem misturar contexto com os outros fluxos.
2. Testar padrão de painel duplo em mobile (empilhamento vertical, barra de ações permanece acessível sem scroll excessivo).
3. Testar fluxo Avatar nas duas abas (script e foto) e confirmar que o polling de status funciona sem travar a UI.
4. Testar Clipes automáticos com um vídeo de exemplo e confirmar que os clipes gerados já saem no formato 9:16 corretos pra Reels.
5. Testar Vídeo em lote com uma planilha pequena (3-5 linhas) e confirmar que cada vídeo é gerado com os dados corretos substituídos no script.
