Objetivo

Quando um cliente enviar um áudio pelo WhatsApp, o sistema deve:


Receber o áudio via Z-API
Transcrever para texto usando OpenAI Whisper
Tratar o texto transcrito EXATAMENTE como se o cliente tivesse digitado
O restante do fluxo (entendimento, estoque, orçamento) continua igual



Como o Z-API entrega áudios

Quando o cliente envia um áudio, o webhook do Z-API chega com este payload:

json{
  "phone": "5548999999999",
  "isGroupMsg": false,
  "type": "audio",
  "audio": {
    "audioUrl": "https://...",
    "mimeType": "audio/ogg; codecs=opus",
    "seconds": 12
  }
}

Para mensagem de texto normal:

json{
  "phone": "5548999999999",
  "type": "chat",
  "text": {
    "message": "quero 50 caixas do produto X"
  }
}

Passo 2 — Criar serviço de transcrição

Arquivo: server/services/transcricaoAudioService.ts

typescriptimport OpenAI from 'openai';
import axios from 'axios';
import * as fs from 'fs';
import * as path from 'path';
import * as os from 'os';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export async function transcreverAudio(audioUrl: string): Promise<string> {
  
  // 1. Baixar o arquivo de áudio da URL do Z-API
  const response = await axios.get(audioUrl, { responseType: 'arraybuffer' });
  const buffer = Buffer.from(response.data);
  
  // 2. Salvar temporariamente em disco (Whisper precisa de arquivo)
  const tmpPath = path.join(os.tmpdir(), `audio_${Date.now()}.ogg`);
  fs.writeFileSync(tmpPath, buffer);
  
  try {
    // 3. Transcrever com Whisper
    const transcricao = await openai.audio.transcriptions.create({
      file: fs.createReadStream(tmpPath),
      model: 'whisper-1',
      language: 'pt',         // português brasileiro
      response_format: 'text' // retorna texto puro
    });
    
    return transcricao.trim();
    
  } finally {
    // 4. Limpar arquivo temporário
    if (fs.existsSync(tmpPath)) {
      fs.unlinkSync(tmpPath);
    }
  }
}

Passo 3 — Atualizar o webhook que recebe mensagens do WhatsApp

Localizar o endpoint que recebe o webhook do Z-API (provavelmente em server/routes/whatsapp.ts ou server/routes/webhook.ts) e adicionar o tratamento de áudio:

typescriptrouter.post('/webhook/whatsapp', async (req, res) => {
  res.status(200).send('ok'); // responder imediatamente para o Z-API não reenviar
  
  try {
    const payload = req.body;
    const telefone = payload.phone;
    const tipo = payload.type;
    
    let textoMensagem = '';
    let ehAudio = false;

    // ── TEXTO NORMAL ──
    if (tipo === 'chat') {
      textoMensagem = payload.text?.message || '';
    }
    
    // ── ÁUDIO ──
    else if (tipo === 'audio' || tipo === 'ptt') {
      // ptt = Push To Talk (áudio do WhatsApp)
      const audioUrl = payload.audio?.audioUrl;
      
      if (!audioUrl) {
        console.warn('Áudio recebido sem URL:', payload);
        return;
      }
      
      // Avisar o cliente que está processando
      await enviarMensagemTexto(telefone, '🎧 Recebi seu áudio! Deixa eu ouvir...');
      
      // Transcrever
      textoMensagem = await transcreverAudio(audioUrl);
      ehAudio = true;
      
      console.log(`[Áudio transcrito] ${telefone}: "${textoMensagem}"`);
    }
    
    // ── OUTROS TIPOS (imagem, vídeo, sticker) ──
    else {
      // Ignorar por enquanto ou responder que não suporta
      await enviarMensagemTexto(
        telefone,
        'Olá! No momento processo apenas mensagens de texto e áudio. Pode me enviar sua solicitação assim? 😊'
      );
      return;
    }
    
    if (!textoMensagem.trim()) return;
    
    // ── PROCESSAR A MENSAGEM (texto ou áudio transcrito) ──
    // A partir daqui é IDÊNTICO para texto e áudio
    
    const tenantId = await buscarTenantPorTelefone(telefone);
    const lead = await buscarOuCriarLead(telefone, tenantId);
    const historico = await buscarHistoricoConversa(lead.id);
    
    const resultado = await processarMensagemLead({
      tenantId,
      leadId: lead.id,
      telefone,
      nomeCliente: lead.nome || 'Cliente',
      empresaCliente: lead.empresa,
      historicoMensagens: historico,
      novaMensagem: textoMensagem,
      origemMensagem: ehAudio ? 'audio' : 'texto' // para log
    });
    
    // Enviar resposta
    await enviarMensagemTexto(telefone, resultado.resposta);
    
    // Salvar mensagem no histórico
    await salvarMensagemHistorico({
      leadId: lead.id,
      tenantId,
      role: 'user',
      content: textoMensagem,
      tipo: ehAudio ? 'audio' : 'texto',
      audioUrl: ehAudio ? payload.audio?.audioUrl : undefined
    });
    
    await salvarMensagemHistorico({
      leadId: lead.id,
      tenantId,
      role: 'assistant',
      content: resultado.resposta,
      tipo: 'texto'
    });
    
  } catch (error) {
    console.error('Erro no webhook WhatsApp:', error);
  }
});

Passo 4 — Atualizar tabela de histórico de mensagens

Adicionar campo tipo e audio_url ao modelo de mensagens no Prisma:

prismamodel MensagemChat {
  id          String   @id @default(uuid())
  tenant_id   String
  lead_id     String
  role        String   // "user" | "assistant"
  content     String   // texto puro (ou transcrição do áudio)
  tipo        String   @default("texto") // "texto" | "audio"
  audio_url   String?  // URL original do áudio se for áudio
  criado_em   DateTime @default(now())

  @@index([lead_id])
  @@index([tenant_id])
}

        ↓
Sistema responde: "🎧 Recebi seu áudio! Deixa eu ouvir..."
        ↓
Whisper transcreve o áudio para texto em pt-BR
        ↓
Texto transcrito entra no fluxo IGUAL ao texto digitado
        ↓
Claude entende o pedido → consulta estoque → gera orçamento → envia PDF
