## Parte B — Colocar automaticamente no funil do CRM

Após criar o lead, criar um deal automaticamente no primeiro stage do funil:

```javascript
// 1. Buscar o funil padrão do tenant (ou o primeiro funil disponível)
const funil = await db.query.pipelines.findFirst({
  where: eq(pipelines.tenantId, tenantId),
  orderBy: asc(pipelines.createdAt)
});

// 2. Buscar o primeiro stage do funil (menor order/posição)
const primeiroStage = await db.query.stages.findFirst({
  where: eq(stages.pipelineId, funil.id),
  orderBy: asc(stages.order)
});

// 3. Criar deal vinculado ao lead
const deal = await db.insert(deals).values({
  tenant_id: tenantId,
  lead_id: lead.id,
  title: `${place.name} — Prospectado`,
  stage_id: primeiroStage.id,
  pipeline_id: funil.id,
  source: 'prospector',
  status: 'open',
  created_by: userId
}).returning();

// 4. Criar activity de entrada
await db.insert(activities).values({
  tenant_id: tenantId,
  deal_id: deal[0].id,
  type: 'lead_imported',
  description: `Lead importado via Prospector. Fonte: Google Places. Avaliação: ${place.rating}★ (${place.user_ratings_total} avaliações).`,
  created_by: 'system'
});
```

## Parte C — Gerar Briefing Automático com IA

Após criar o lead e o deal, disparar geração de briefing via OpenAI:

```javascript
async function gerarBriefingLead(place, lead, deal) {
  const prompt = `
Você é um analista de inteligência comercial. Com base nos dados abaixo de uma empresa 
prospectada, gere um briefing comercial estruturado para orientar o time de vendas.

DADOS DA EMPRESA:
- Nome: ${place.name}
- Categoria: ${place.types?.join(', ')}
- Endereço: ${place.formatted_address}
- Telefone: ${place.phone ?? 'não disponível'}
- Site: ${place.website ?? 'não disponível'}
- Avaliação Google: ${place.rating}★ com ${place.user_ratings_total} avaliações
- Horário de funcionamento: ${place.opening_hours?.weekday_text?.join(' | ') ?? 'não disponível'}

Gere um briefing com exatamente estas seções:

1. PERFIL DO NEGÓCIO (2-3 linhas): O que a empresa faz, porte estimado, posicionamento
2. PONTOS DE DOR PROVÁVEIS (3 bullets): Principais problemas que esse tipo de negócio enfrenta em vendas, atendimento e gestão
3. OPORTUNIDADE VENDOR.AI (2-3 linhas): Como a Vendor.ai resolve os problemas identificados para esse negócio específico
4. ABORDAGEM RECOMENDADA (1-2 linhas): Tom e ângulo ideal para a primeira abordagem
5. SCORE DE POTENCIAL: Alta / Média / Baixa — com justificativa em 1 linha

Seja específico para o segmento e localidade. Não seja genérico.
`;

  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: prompt }],
    max_tokens: 600
  });

  const briefing = response.choices[0].message.content;

  // Salvar briefing no deal
  await db.update(deals)
    .set({ 
      ai_briefing: briefing,
      ai_briefing_generated_at: new Date()
    })
    .where(eq(deals.id, deal.id));

  return briefing;
}
```
