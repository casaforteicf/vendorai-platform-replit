# Atribuição de crescimento de seguidores

Esta camada usa o crescimento líquido de seguidores do Meta Growth, visitas ao perfil e o peso relativo de engajamento dos conteúdos recentes para estimar influência por conteúdo.

Não representa atribuição causal direta da Meta. O painel identifica a estimativa explicitamente e usa o dado apenas para priorização de conteúdo e mídia.
