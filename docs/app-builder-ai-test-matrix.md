# Matriz de qualidade — Arquiteto IA

| Dimensão | Deve verificar | Falha bloqueante |
|---|---|---|
| Produto | jornadas, exceções, objetivos | fluxo principal inexistente |
| UX | mobile, navegação, clareza de tarefa | navegação inválida |
| Segurança | menor privilégio, ações críticas | permissão/action incompatível |
| Dados | entidades, fontes e bindings | fonte inventada como existente |
| Integração | dependências reais e gaps | integração inexistente tratada como pronta |
| Runtime | páginas, IDs, blocos, defaultPageId | incompatibilidade determinística |
| Governança | rascunho, revisão, publicação humana | publicação automática pela IA |

A matriz complementa os testes automatizados e o benchmark canônico.
