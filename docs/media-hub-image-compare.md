# Media Hub — comparação e histórico de imagem

Esta entrega adiciona comparação original x resultado e histórico de versões diretamente no Assistente de Melhoria da Central de Mídias.

Regras preservadas:
- original imutável;
- versões derivadas registradas na mesma biblioteca;
- comparação usa a linhagem existente por `metadata.sourceAssetId`;
- nenhuma tabela ou biblioteca paralela é criada.
