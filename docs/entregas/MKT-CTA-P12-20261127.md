# MKT-CTA-P1.2 — Link e UTM na publicação orgânica

Data: 2026-11-27
Branch: `feat/mkt-cta-p12` (base `main` @ 1735f1a38)

## Objetivo
Fazer o CTA chegar ao destino: anexar o link resolvido (com UTM) na legenda/descrição publicada.

## Entregue
- `media-plan-scheduled-publication` resolve o CTA da peça e compõe o texto:
  - **Facebook, LinkedIn, YouTube**: link clicável em linha separada;
  - **Instagram, TikTok**: “Link na bio: <url>” (não há link clicável);
  - outros provedores: texto original.
- URL vem de `resolvePieceCta` (WhatsApp/LP/site) com UTM
  (`utm_source=canal`, `utm_medium=organic`, `utm_campaign`, `utm_content=peça`).
- Sem destino configurado → legenda permanece como era (nada inventado).
