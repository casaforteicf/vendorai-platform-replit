# MKT-CTA-P1 — CTA com destino e UTM (P1)

Data: 2026-11-27
Branch: `feat/mkt-cta-p1` (base `main` @ 101fc9e5f)

## Objetivo
O CTA do criativo deixa de ser só texto: passa a ter **destino resolvido** (WhatsApp, LP do
tenant ou site) e **UTM** para atribuição.

## Entregue (P1.1)
- **Contrato puro** (`@workspace/vendor-brain`):
  - `pieceCtaLabel(destination, objective)` — “Falar no WhatsApp”, “Ver oferta”, “Saiba mais”…
  - `appendUtm(url, {source, medium, campaign, content})` — não sobrescreve UTM existente.
  - **4 testes**.
- **Serviço** `resolvePieceCta`: WhatsApp (click-to-chat com UTM), LP publicada do tenant
  (`<slug>.appvendorai.com`) ou site; nunca inventa URL (retorna `null`).
- **API**: `GET /marketing/pieces` e `GET /marketing/pieces/:id` agora devolvem `cta`
  `{ label, destination, url }` por peça.
- **Revisão**: abaixo do campo CTA mostra **“Destino: … · host”** ou aviso para configurar
  WhatsApp/LP.

- API build: **EXIT 0**.
